# Face map model

`face_landmarker.task` is Google MediaPipe's Face Landmarker model (float16, version 1), Apache-2.0,
from https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task
(sha256 64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff).

It runs in the listener's browser to find the mouth and eyes on a host's invented photo, so the
photo can talk and blink. Nothing is sent anywhere.
